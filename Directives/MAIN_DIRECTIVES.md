# IT Responsibility Quest

## Goal
The goal of this project is to provide a gamified IT responsibility matrix application. This helps teams and clients understand who is responsible for what in a fun and engaging way.

## Guidelines
- Maintain a clean and modern UI/UX.
- The "Jane AI" assistant should remain sarcastic but helpful.
- Ensure all components are responsive and performant.

## Tech Stack
- Frontend: React 18, Vite, Tailwind CSS, Framer Motion.
- Backend: Node.js, Express, PostgreSQL.
- Infrastructure: Docker, Nginx.
